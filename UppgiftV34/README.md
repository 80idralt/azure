# Uppgift V34 - Compute: driftsättning av Novatrix kundtjänst

#### Idris Altun
#### Azure
## Syfte 
Veckans uppgift gick ut på att sätta upp en virtuell maskin i Azure, versionshantera allt i GitHub och skapa ett kundtjänstsida med ett ärendeformulär

## Vad jag gjorde
- Provisionera en virtuell maskin i Azure
- Basera den på Ubuntu
- Konfigurera värdmiljön
- Ansluta till servern via SSH och installera webservern Nginx
- Driftsätt kundstjänstsidan med ärendeformulär
- Verifierade att sidan och formuläret går att nå
